## Что делает проект

- 🌡️ **Датчики (I2C через MGB-P8 / MGB-I2C63)**: давление/температура воздуха (BMP280), освещённость (MGS-L75), УФ-индекс (MGS-GUVA через ADS1015 / MGB-D1015), температура/влажность почвы (MGS-TH50, аналог).
- 🚪 **Автовентиляция**: сервопривод открывает заслонку при температуре ≥ 30 °C, закрывает при ниже. В ручном режиме заслонка остаётся в заданном положении.
- 💡 **LED-матрица 8×8**: цвет по температуре (зелёный < 25 °C, жёлтый 25–30 °C, красный ≥ 30 °C) + индикация состояния заслонки по углам (синий — открыта, пурпурный — закрыта).
- 🔌 **Два реле (MGR-2)** с таймером от 1 сек до 24 ч.
- 🌐 **Веб-интерфейс** с авторизацией: дашборд, данные датчиков в реальном времени, управление матрицей/серво/реле, настройки пинов и порогов.
- 📊 **Логирование**: последнее измерение датчиков в JSON через `/api/sensors` (без исторических графиков).

## Схема подключения

### Общая схема

```
                    ЙоТик 32A v2.1 (ESP32, MG Bot)
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  GPIO21 (SDA) ┐                                                     │
│  GPIO22 (SCL) ┼───────┬───────────────────────────────────────────┐│
│               │       ▼                                           ││
│               │   MGA-RJ9   (переходник RJ-9)                     ││
│               │       │      →  MGB-I2C63 (плата расширения RJ-9) ││
│               │       │            │                               ││
│               │       │            │ SDA/SCL (I2C шина)            ││
│               │       │            ▼                               ││
│               │       │        MGB-P8  (I2C-разветвитель 8× RJ-9)  ││
│               │       │            ├─► BMP280   (давление/темп.)   ││
│               │       │            ├─► MGS-L75  (освещённость)     ││
│               │       │            ├─► ADS1015  (АЦП MGS-GUVA)     ││
│               │       │            └─► ...                         ││
│               │                                                      ││
│  GPIO18 ───────────────────────► WS2812 8×8 LED-матрица (DIN, 5V) ││
│  GPIO19 ───────────────────────► Сервопривод 360° (сигнал, 5V)     ││
│  GPIO13 ───────────────────────► Реле 1 (MGR-2 CH1, IN)            ││
│  GPIO14 ───────────────────────► Реле 2 (MGR-2 CH2, IN)            ││
│  GPIO32 ───────────────────────► MGS-TH50 влажность (аналог AO)    ││
│  GPIO33 ───────────────────────► MGS-TH50 температура (аналог AO)  ││
│                                                                     │
│  3.3V ─────────────────────────────────► VCC I2C-датчиков          ││
│  5V  ──────────────────────────────────► VCC матрица/серво/реле    ││
│  GND ───────────────────────────────────► GND всех модулей         ││
└─────────────────────────────────────────────────────────────────────┘

Питание: MGA-PWR8 (плата питания 5V) → матрица, серво, реле.
Цепочка: ЙоТик 32A v2.1 → MGA-RJ9 → MGB-I2C63 → MGB-P8 → BMP280 / MGS-L75 / ADS1015 (MGS-GUVA)
```

### Подключение I2C-датчиков через расширители

Все I2C-датчики (**BMP280, MGS-L75, ADS1015/MGS-GUVA**) подключены к одной шине I2C (SDA — GPIO 21, SCL — GPIO 22) через платы расширения:

- **Плата расширения I2C MGB-P8** — разводит шину на 8 портов RJ-9 для подключения датчиков.
- Контроллер **ЙоТик 32A v2.1** подключён к **плате расширения RJ-9 MGB-I2C63** через переходник **MGA-RJ9**, а от неё шина уходит через **MGB-P8** к датчикам.

Соединение: `ЙоТик 32A v2.1 (SDA/SCL)` → `MGA-RJ9` → `MGB-I2C63` → `MGB-P8` → `BMP280 / MGS-L75 / ADS1015 (MGS-GUVA)`.

### Подробная таблица подключения

| Компонент | Вывод компонента | Пин ЙоТик 32A | Примечание |
|---|---|---|---|
| **MGA-RJ9** | — | — | переходник RJ-9 (ЙоТик → MGB-I2C63) |
| **MGB-I2C63** (RJ-9) | SDA/SCL | GPIO 21/22 | плата расширения, источник I2C |
| **MGB-P8** (I2C) | SDA/SCL | GPIO 21/22 | разветвитель 8× RJ-9 |
| **BMP280** (давление) | SDA/SCL | GPIO 21/22 | I2C, адрес 0x76/0x77 |
| **MGS-L75** (освещённость) | SDA/SCL | GPIO 21/22 | I2C, BH1750FVI, адрес 0x23/0x5C |
| **ADS1015** / **MGB-D1015** | SDA/SCL | GPIO 21/22 | I2C, адрес 0x48–0x4B, АЦП для MGS-GUVA |
| **MGS-GUVA** (УФ) | → ADS1015 A0 | — | аналог через ADS1015 |
| **MGS-TH50** влажность | AO | GPIO 32 | аналоговый вход |
| **MGS-TH50** температура | AO | GPIO 33 | аналоговый вход |
| **WS2812 8×8** | DIN | GPIO 18 | питание 5V, общий GND |
| **Сервопривод 360°** | Сигнал | GPIO 19 | питание 5V |
| **MGR-2 реле CH1** | IN1 | GPIO 13 | активный уровень HIGH |
| **MGR-2 реле CH2** | IN2 | GPIO 14 | активный уровень HIGH |
| **MGA-PWR8** | — | — | плата питания 5V (матрица, серво, реле) |

### Питание

- ЙоТик 32A v2.1 — от USB или внешнего 5V.
- Датчики I2C (BMP280, MGS-L75, ADS1015) — **3.3V**.
- LED-матрица WS2812, сервопривод и реле — **5V** от платы питания **MGA-PWR8**.
- Общий **GND** для всех модулей обязателен.

## Как всё работает

### Цикл main loop (каждые 2 сек)

1. `webServer->loop()` — обработка HTTP-запросов.
2. `relays.update()` — таймеры реле.
3. Чтение всех датчиков (`readAllSensors()`).
4. Логирование в `SensorLogger` (последнее измерение).
5. Если `isServoAutoMode()==true` → `controlVentilation(temp)` — открывает/закрывает заслонку по порогу 30 °C.
6. Обновление LED-матрицы (`updateDisplay`).

### Автоматика заслонки

- `controlVentilation(float temp)` вызывается только в автоматическом режиме.
- При `temp >= TEMP_THRESHOLD` (30 °C) → `servo.open()` (открыть заслонку).
- При `temp < TEMP_THRESHOLD` → `servo.close()` (закрыть заслонку).
- В ручном режиме (после нажатия «Открыть»/«Закрыть»/«Стоп») автоматика отключается; кнопка «Автоматическое управление» возвращает авто-режим.

### LED-матрица

- Цвет по температуре: зелёный (< 25 °C), жёлтый (25–30 °C), красный (≥ 30 °C).
- Четыре угла матрицы показывают состояние заслонки: синий — открыта, пурпурный — закрыта.
- Пользовательский цвет через `/api/matrix` отключает автоматический режим цвета.

### Калибровка

При первом запуске выполняется калибровка MGS-TH50 в течение 10 секунд (матрица светится оранжевым). В это время в Serial выводятся сырые значения АЦП для влажности и температуры.

### Веб-интерфейс

- Одностраничное приложение (HTML в PROGMEM, `WebPage.h`).
- Обновление данных каждую секунду (`setInterval`).
- Данные датчиков из `/api/sensors`.
- Авторизация Basic Auth (root/admin).

## Веб-сервер

### Общие сведения

- Порт: `WEB_SERVER_PORT` (по умолчанию **80**).
- Авторизация: **Basic Auth**, логин `root`, пароль `admin`.
- При подключении к WiFi — STA-режим; при неудаче — AP `Greenhouse` / `123456789`, IP `192.168.4.1`.
- Логотип авторизации: SVG с 🌱, маршрут `/img/logo`.

### Интерфейс (веб-страница)

На странице две вкладки:

**Дашборд:**
- Карточки с текущими показаниями: температура/влажность почвы (MGS-TH50), освещённость (MGS-L75), температура/давление воздуха (BMP280), УФ-индекс (MGS-GUVA)
- Статус подключения к WiFi (онлайн / точка доступа / демо)
- Управление LED-матрицей: выбор цвета, кнопка «Авто (по температуре)»
- Управление сервоприводом: кнопки Открыть / Закрыть / Стоп / Автоматическое управление
- Управление реле: включение канала 1 или 2 на заданное время

**Настройки:**
- Порог температуры автовентиляции (по умолчанию 30 °C)
- Время открытия и закрытия заслонки в мс
- Настройки WiFi (SSID, пароль, точка доступа)
- Пины оборудования (серво, реле, матрица, I2C)
- Кнопка сканирования I2C-шины

### Как авторизоваться

При первом открытии страницы apparaît окно входа:
- Логин: `root`
- Пароль: `admin`
- После успешного входа открывается полный доступ ко всем эндпоинтам и элементам управления.

## Как что поменять

### Порог температуры
- В коде: `TEMP_THRESHOLD` в `sketch_oct9a/src/config.h` (по умолчанию `30.0f`).
- В веб: вкладка «Настройки» → «Порог температуры авто» → «Сохранить».

### Время открытия/закрытия заслонки
- `SERVO_OPEN_TIME_MS` / `SERVO_CLOSE_TIME_MS` в `sketch_oct9a/src/config.h`.
- Или через веб: «Время открытия заслонки (мс)» / «Время закрытия заслонки (мс)».

### WiFi
- `WIFI_SSID` / `WIFI_PASSWORD` в `sketch_oct9a/src/WebConfig.h`.

### Интервал чтения датчиков
- `LOG_INTERVAL_MS` (по умолчанию 2000 мс) в `sketch_oct9a/src/WebConfig.h`.
- `LOOP_DELAY_MS` (по умолчанию 2000 мс) в `sketch_oct9a/src/config.h`.

### Пины
- Константы в `sketch_oct9a/src/config.h` или через веб (сохраняются в NVS, применяются при перезагрузке).

### Серво в автоматике
- `controlVentilation()` вызывается только при `webServer->isServoAutoMode()==true`.
- Ручные команды (open/close/stop) переключают в ручной режим.
- Кнопка «Автоматическое управление» возвращает авто-режим.

### Авторизация
- Логин/пароль: `checkAuth()` в `sketch_oct9a/src/WebServer.h` (`server.authenticate("root", "admin")`).

## Сборка и прошивка

1. Установить **Arduino IDE** + пакет плат **ESP32** (Espressif).
2. Установить библиотеки через Library Manager:
   - [`Adafruit NeoPixel`](https://github.com/adafruit/Adafruit_NeoPixel) — управление LED-матрицей WS2812
   - [`ESP32Servo`](https://github.com/madhephaestus/ESP32Servo) — управление сервоприводом 360°
   - [`Adafruit ADS1X15`](https://github.com/adafruit/Adafruit_ADS1X15) — АЦП ADS1015 для MGS-GUVA
   - `Adafruit BMP280 Library` (в проекте используется собственная реализация `Bmp280`, библиотека опциональна)
3. Открыть `sketch_oct9a/sketch_oct9a.ino`.
4. Выбрать плату: **ESP32 Dev Module**.
5. Выбрать порт COM.
6. Нажать **Upload**.
7. Открыть Serial Monitor (115200) — IP-адрес выведется при старте.
8. При первом запуске пройдёт калибровка MGS-TH50 (10 сек).
